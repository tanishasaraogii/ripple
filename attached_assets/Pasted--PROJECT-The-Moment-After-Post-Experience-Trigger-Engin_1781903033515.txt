# PROJECT: The Moment After — Post-Experience Trigger Engine

## Context
4-hour solo hackathon project for Headout (experiences/tours booking platform).
Judged live on stage in a ~3 min demo. Win condition: a working demo that shows
a WhatsApp-style message firing the moment a tour ends, recommending the perfect
next experience nearby. This is a revenue recovery play — same-day second
booking from existing customers at peak travel euphoria. Zero new users needed,
zero CAC, pure conversion from people who already trust Headout.

## The Problem We're Solving
After a guest completes an experience, Headout goes silent. That guest is
standing somewhere amazing, still buzzing, with hours left in their day.
Headout already knows:
- What they just did
- Where the experience was (location in listing)
- What time it ended (from booking)
- What's bookable nearby right now
- Their booking history and preferences

Nobody is sending them anything. We fix that with one perfectly timed,
hyper-personalized WhatsApp message that fires at experience end time.

## CORE PRINCIPLE: DEMO-FIRST, ZERO EXTERNAL DEPENDENCIES
The app MUST run fully and demo end-to-end with NO API keys and NO network
calls. Every core feature works locally. WhatsApp delivery is SIMULATED
visually — we show the message UI on screen. No real WhatsApp API needed.
No database. No auth. In-memory state only. NO localStorage/sessionStorage.

### 2. RECOMMENDATION ENGINE (deterministic rules, no ML)
Given a completed experience, select the best next recommendation:
- NEVER same category as what they just did
- Prefer experiences ending 2+ hours before sunset (assume sunset 8pm)
- If solo: weight toward food and adventure
- If group: weight toward landmark and shows
- Always pick the option with lowest available_slots first (scarcity signal)
- Distance must be under 20 min walking
- Return top 1 recommendation with full details

### 3. MESSAGE COMPOSER
Given the recommendation, compose a WhatsApp message string:
Format exactly:
"[First name]! Your [experience name] just wrapped 🎉

[Recommendation name] is [X] min away and has [N] slots left today.

[highlight_line]

[Price] · Books in 30 seconds 👇
[fake Headout deep link]"

Keep it under 4 lines. Punchy. No corporate speak. Feels like a friend texted.
